# PharmaLab – Pharmaceutical Laboratory Quality Management System

> **Academic Prototype Disclaimer:** PharmaLab is a B.Tech Integrated Full-Stack Project (AI & ML Specialization) built with React, FastAPI, SQLAlchemy, and Microsoft Azure. It is not a regulatory-validated cGMP system.

## Quick Start in Visual Studio Code

1. Open Visual Studio Code.
2. Go to **File -> Open Folder...** and select this `pharmalab` folder (or open `pharmalab.code-workspace`).
3. Install recommended extensions when prompted by VS Code (`.vscode/extensions.json`).
4. Use **Terminal -> Run Task...** (`Ctrl+Shift+P` -> `Tasks: Run Task`) and select:
   - `1. Setup Backend Virtual Env & Dependencies`
   - `2. Setup Frontend Node Packages`
   - `3. Start Full-Stack PharmaLab (Backend + Frontend)`
5. Or press **F5** to launch the **FastAPI Backend + React Frontend** compound debugger configuration.
