# 💊 PharmaLab – Pharmaceutical Laboratory Quality Management System

PharmaLab is a secure, cloud-based platform designed to manage pharmaceutical laboratory quality-control activities. It helps laboratories manage medicine batches, record test results, track quality deviations, and monitor corrective actions through a centralized system.

## 🎯 Project Objectives

* Manage pharmaceutical products and medicine batches.
* Record laboratory samples and test results.
* Automatically identify pass/fail test results.
* Track quality deviations and corrective actions (CAPA).
* Maintain secure records with role-based access.
* Generate quality reports and analytical dashboards.

## 👥 Target Users

* Laboratory Technicians
* Quality Control (QC) Officers
* Quality Assurance (QA) Officers
* Laboratory Administrators and Managers

## ⚙️ Key Features

* Product and Batch Management
* Laboratory Sample Management

## 🏗️ System Architecture

PharmaLab follows a three-tier architecture:

1. **Presentation Layer:** React.js frontend.
2. **Application Layer:** Python FastAPI backend and REST APIs.
3. **Data Layer:** Azure SQL Database and Azure Blob Storage.
